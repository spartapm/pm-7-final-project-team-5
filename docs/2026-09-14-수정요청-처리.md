## 2. 홈 / 계획

| 요청 | 상태 | 처리 |
| --- | --- | --- |
| 확인 1) 해당 유형 기록 3건 이상·인사이트 없음: `아직 눈에 띄는 경향이 확인되지 않았어요. 기록을 추가해보세요` (1순위) | ✅ | 링별 `count >= 3`일 때 문구 교체. 3건 미만은 기존 문구 |
| 확인 2) 계획 검색, 팝업 X 후 백스페이스로 종목명 전부 삭제 (1순위) | ✅ | `StockSearch`가 빈 입력을 선택 종목명으로 되돌리지 않음. 지우면 최근 검색 노출. 매매기록 4-1b와 동일 컴포넌트 |
| 확인 3) 해외 계획 화면 안내 텍스트 상자 삭제 (2순위) | ✅ | `해외 종목은 가격을 달러…` 힌트 삭제 |

## 4. 매매기록 확인

09.11에서 뺐던 연필·목록 CTA를 **09.14가 다시 넣으라고 해서** 복구했다.

| 요청 | 상태 | 처리 |
| --- | --- | --- |
| 항목 1) `매매 정보` 타이틀 + 구분 매수 `#476B9E` / 매도 `#C75A6A` (2순위) | ✅ | 상세 카드. 일시는 `매수일시`/`매도일시`. `.detail-kv dd`가 `.side-buy`를 덮어 매수가 `#253247`로 보이던 건 선택자 우선순위로 수정 |
| 항목 2) 매매정보 수정 연필 → 5-10/5-11 (1순위) | ✅ | `/records/[id]/edit`. 가격·수량·일시만 수정 (`TradeWizard` edit). GA `record_edit_*` |
| 항목 3) 하단 `기록 목록 확인하기` (1순위) | ✅ | 상세 하단 CTA → `/records`. GA `record_detail_list_cta_click` |
| 항목 4) 계획 범위 밖이면 범위 바 숨김 (2순위) | ✅ | `inRange`일 때만 `.range-bar`. 캡션은 유지 |
