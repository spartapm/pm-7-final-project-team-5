# 5조 2026.09.11 수정 요청사항 — 처리 결과

기준: 피그마 [5조 · 2026.09.11 - 수정 요청사항](https://www.figma.com/design/4vkt1I8oKaDETSNRHXF4ns/5%EC%A1%B0?node-id=3136-1709)  
확인: 2026-09-13 · `localhost:3005`

피그마 MCP는 편집 권한이 없어 캔버스를 직접 확대(50%)해 항목을 읽었다. 인사이트 항목 3의 **당시 상태 차트 표시 문구** 표는 50%에서 글자까지 확인했다.

| 표시 | 의미 |
| --- | --- |
| ✅ | 요청대로 반영했고, 코드/화면에서 확인함 |
| ⚠️ | 동작·밀도는 맞췄으나 피그마 에셋·세부 카피가 불완전함 |
| ❌ | 안 함 (피그마가 유지 제안 / 웹에서 해당 화면 없음 / 에셋 없음) |

## 0. 공통

피그마 왼쪽 **설명** 블록 + 섹션 프레임(공통 / 온보딩 / 2.홈 / 3.계획 / 매매기록 / 5.매매 기록 조회 / 인사이트)을 기준으로 항목을 나눴다.

| 요청 | 상태 | 어떻게 처리했는지 | 결과 |
| --- | --- | --- | --- |
| 1. 뒤로 가기·확인 CTA 위치는 5메뉴와 충돌하니 **현재 상태 유지** | ❌ | 피그마 설명이 “현재 상태 유지 제안”. 헤더 좌측 뒤로가기 + 하단 고정 CTA를 그대로 둠 | 위치 변경 없음 (요청이 유지) |
| 2. 섹션 간 여백 — Card 내부 16px, 섹션 24–32px, 빈 화면 밀도 회복 | ✅ | `.card` padding `20→16`, `.card + .card` `16→12`, `.plan-row`/`date-group` 패딩·간격 축소 | 계획 리스트·인사이트 카드가 덜 비어 보임 |
| 2) 5-1 기록(계획) 리스트 여백 | ✅ | 리스트 위 보조 문구 삭제 + 행 패딩 축소. 카드가 위쪽에 붙도록 유지 | 한 장만 있어도 하단이 과하게 비지 않게 밀도만 맞춤 |
| 2) 6-7 인사이트 날짜별 카드 전체보기 | ✅ | 날짜 그룹 패딩 12px, 하단 보존 문구 마진 16→12 | 카드 사이 공백이 줄어듦 |
| 2) 6-8 관련 기록 모두보기 | ✅ | 기록 행이 이미 `trade-card` 카드형. 공통 카드 패딩을 16px로 맞춤 | 목록 카드 너비·내부 여백 통일 |
| 3. 온보딩 0-5의 **0-6 가기 / 뒤로가기** 삭제, 하단 **다음**만 | ✅ | 판단근거·마음 단계(`reason`/`mood`)에서 헤더 뒤로가기 제거. 하단 CTA는 `다음` | 0-5에서 뒤로가기가 안 보임 |
| 4. 「어떤 메뉴 선택하실지」 팝업 삭제, 종료 후 코치마크/시트 | ✅ | 웹에 그 팝업은 원래 없음. 홈 첫 진입 시 하단 시트 `메뉴를 이렇게 써 보세요`(홈·계획·기록·인사이트). `localStorage` `inplot:seen-coach`로 한 번만 | 팝업 없음. 확인 누르면 다시 안 뜸 |
| 5. 기록 조회 필터/검색어 유지 | ✅ | `sessionStorage` `inplot:records-filter`에 전체/매수/매도 저장 | 매수 필터 → 상세 → 목록 복귀 후에도 **매수**가 유지됨 |

## 6. 인사이트 · 차트 (중점)

피그마 AS-IS는 **도넛(가운데 구멍)** 이고 TO-BE는 **채워진 파이**. 항목 3 표의 3열이 **차트 표시 문구**(사용자 노출), 2열 메타는 내부용.

| 요청 | 상태 | 어떻게 처리했는지 | 결과 |
| --- | --- | --- | --- |
| 항목 1) 대시보드 **도넛 → 파이** | ✅ | `PieChart`가 원점부터 wedge `path`를 채움(홀 없음). 슬라이스 사이 흰 stroke 2px. 한눈에 보기 132px, 범례는 이름 / `n건 · n%` 2줄, 원형 스와치 | `localhost:3005/insights`에서 채워진 파이 확인. 범례가 카드 안에서 한 줄씩 안 깨짐 |
| 항목 2) 판단 이유 자세히 보기 차트 | ✅ | 대분류 제목을 파이 위에 풀폭으로 두고, 작은 파이(88px)+범례. 범례는 판단근거 `meta`(차트용 짧은 문구) | 「자세히 보기」에서 `주요 지수 급등락`, `실적발표`, `배당 공시`처럼 짧은 라벨 + 파이 |
| 항목 3) 매매 당시 마음 상태 · 범례 텍스트 차트용 문구 | ✅ | 피그마 표 3열을 `MOOD_MAP.chart`로 넣음. `moodDistribution`이 긴 문장 대신 차트 문구를 씀. 매수 96px 블루 파이 / 매도 96px 골드 파이 | 예: 매수 「계획대로 진행」「타이밍 놓칠 우려」, 매도 「추가 하락 우려」「계획대로 진행」 |
| 항목 4) narrative1 | ✅ | `.narrative1` 13px 보조 문단 | 관찰 문장이 작게 |
| 항목 5) narrative2 폰트 | ✅ | `.narrative2` 15px Bold | 해석 문장이 제목 역할 |
| 항목 6) 대시보드 탭 미리보기 이미지 | ✅ | 기록 0건 캐러셀: 매매 추이=미니 라인, 판단 근거=파이, 계획=바, 매수/매도 마음=파이 | 빈 대시보드 예시도 도넛이 아니라 파이/라인 |

### 차트 표시 문구 (피그마 항목 3 표)

내부 메타(비노출)는 그대로 두고, **차트에만** 아래 문구를 쓴다.

**매수**

| 화면에 보이는 문장 | 차트 표시 문구 |
| --- | --- |
| 계획대로여서 특별한 느낌은 없었다 | 계획대로 진행 |
| 많이 떨어져 있어서 지금이 기회라고 봤다 | 저가 진입 판단 |
| 오르는 중이었지만 더 갈 거라고 봤다 | 상승 지속 기대 |
| 지금 아니면 놓칠 것 같았다 | 타이밍 놓칠 우려 |
| 앞서 본 손실을 빨리 되돌리고 싶었다 | 손실 회복 기대 |
| 다들 사는 분위기라 나만 빠지는 것 같았다 | 시장 분위기 영향 |
| 확신은 없었지만 일단 들어가 봤다 | 확신 없이 진입 |

**매도**

| 화면에 보이는 문장 | 차트 표시 문구 |
| --- | --- |
| 계획한 지점이라 담담했다 | 계획대로 진행 |
| 가격이 급하게 떨어지는 상황에서 더 떨어질까 봐 무서웠다 | 추가 하락 우려 |
| 지금 이익이 사라질까 봐 조급했다 | 이익 감소 우려 |
| 산 가격까지 다시 올라와서 마음이 놓였다 | 본전 회복 안도 |
| 버티면 오를 줄 알았는데 결국 접었다 | 반등 기대 무산 |
| 왜 팔았는지 나도 잘 모르겠다 | 판단 근거 불명확 |
| 다른 데 돈이 필요했다 | (집계 제외, 파이 미포함) |
